A full-featured, cloud-synced restaurant management system with online ordering, catering quotes, and real-time menu management.

## ✨ Features

### 🍕 Customer Features
- **Digital Menu** - Browse categorized dishes with prices and descriptions
- **Smart Search** - Search by dish name, category, or description
- **WhatsApp Ordering** - One-click ordering via WhatsApp integration
- **Catering Quotes** - Generate professional PDF quotes for events
- **QR Code** - Share your menu via QR code on flyers and social media

### 👨‍🍳 Admin Features
- **Menu Management** - Add, edit, or delete menu items with images
- **Order Tracking** - View all customer orders and catering inquiries
- **Real-time Sync** - Changes reflect instantly across all devices
- **Image Upload** - Drag-and-drop dish photos with automatic compression
- **Analytics** - Track order history and catering requests

### ☁️ Cloud Integration
- **Firebase Firestore** - Real-time database for menu and orders
- **Firebase Storage** - Cloud storage for dish images
- **Offline Support** - Works offline with automatic sync when online
- **Multi-device** - Update once, reflect everywhere
